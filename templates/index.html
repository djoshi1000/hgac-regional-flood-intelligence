WHAT-IF RAINFALL

Rainfall Scenario Lab

Example: “What if 11 inches falls over 5 hours in this selected bayou?” The app converts rainfall to a basin runoff hydrograph, then runs the cached local flood screen.

Important: Google Flood Hub does not accept an arbitrary rainfall total as a custom forcing through its public forecast API. This what-if run therefore uses a transparent NRCS Curve Number + SCS runoff hydrograph and the local LiDAR/HAND screen. Flood Hub stays on the dashboard as an independent live comparison.

HOW TO USE THIS APP

Only two things are required

  1. Click a waterway. That polyline/branch is the model target.
  2. Click Run complete analysis. Gauge screening, historical records, rainfall, DEM/HAND, rating curve, NWM/Flood Hub and flood mapping are handled automatically.
The first run can take time because DEM and terrain products are built. They are cached, so future live refreshes are much faster.
